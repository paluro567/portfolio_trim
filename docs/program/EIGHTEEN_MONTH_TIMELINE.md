## Why silent drift is impossible

1. **Every quarter has a mandatory governance review with one counted question.**
2. **Three gates can terminate the programme** (G1, G5, G7) and each has a written FAIL consequence.
3. **G5 at month 6 costs $120** — the cheapest possible route to *"this can never work."*
4. **The purchase requires a sponsor signature citing four evidenced conditions**, so it cannot happen by momentum.
5. **Zero promotions for four quarters forces a formal redefinition** — the drift failure mode is itself gated.
