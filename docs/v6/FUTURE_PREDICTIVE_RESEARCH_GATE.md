# Future Predictive Research — Authorization Gate

**Date:** 2026-08-04 · **Status of any broad predictive study: NOT AUTHORIZED.**

No predictive discrimination study may be designed, funded, or executed until **every** condition below is met and recorded. Each derives from a completed finding, not from preference.

| # | Condition | Threshold | Source |
|---|---|---|---|
| G1 | Survivorship-controlled universe **including delisted securities**, PIT constituents | ≥100 securities | Peer review M1, M9 |
| G2 | Independent resampling units | ≥30 clusters (vs 7 today) | Peer review 2.3; measured FP 0.020–0.095 |
| G3 | Resampling method validated at the actual cluster count | FP rate within [0.03, 0.07] at nominal 0.05, **measured** | Arm 1 FP 0.095 at 1y |
| G4 | Predeclared MDE | **≤ 0.03**, frozen before execution | Observed IC ≤ 0.052 vs 0.10 floor |
| G5 | Primary endpoint | **Rank IC**, not Brier. Calibration evaluated separately and never substituted. | Brier decomposition: dispersion 107–132% |
| G6 | Durable executable harness | Committed under version control, hashed, re-executable by a third party | Arm 1 / Arm 1.5 harnesses destroyed |
| G7 | No holdings-based universe selection | Universe constructed by a rule fixed before data inspection | Peer review Part 3 |
| G8 | Reproducible provenance | Environment lock, DB snapshot identifier, seed metadata, input hashes | B-07 |
| G9 | Models verified cross-sectionally live **by measurement** | Within-date cross-sectional SD > 0 for every model counted | Arm 2 method; `valuation` was 100% neutral |
| G10 | B-07 resolved or the Arm 1 extended grid formally withdrawn | — | Unresolved reproducibility failure |

**Gate rule:** G1 requires commercial data. Commercial data is authorised **only** when G4–G9 are frozen in a preregistration. This ordering is deliberate — it prevents buying data to justify a study, and prevents designing a study around data already bought.

**Standing prohibition:** the seven-security panel may never again be used for an inferential claim. It remains valid as a fixture for software regression and methodology demonstration only.
