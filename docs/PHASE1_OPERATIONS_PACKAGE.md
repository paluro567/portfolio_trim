# PART 1 — CONSOLIDATED PROTOCOL

## 1.1 Primary hypothesis (frozen)

> Reading a V3 report changes a portfolio manager's **committed** intended action or magnitude at a rate
> materially above the rate at which their decision changes on reconsideration with no new information —
> **and** those changes, judged blind by external professionals against externally-authored constraint
> lists, are **not predominantly unsupported or degraded**, **and at least some** are judged to improve
> material-constraint engagement.

## 1.2 Secondary hypotheses

- **H2** Policy-violation detection improves pre → post.
- **H3** Participants accept abstention as a legitimate output.
- **H4** *(exploratory)* Absence of a synthetic score does not impair triage.

## 1.3 Design

Within-participant, committed pre/post, **sham-controlled**. Seven cases per participant.

| Case | Code | Condition | Role |
|---|---|---|---|
| 1 | **A** | commit → V3 report → re-elicit | Confirmatory |
| 2 | **B** | commit → V3 report → re-elicit | Confirmatory |
| 3 | **C** | commit → V3 report → re-elicit | Confirmatory |
| 4 | **D** | commit → V3 report → re-elicit | Confirmatory |
| 5 | **E** | commit → V3 report → re-elicit | Confirmatory |
| 6 | **F** | commit → 3-min distractor → re-elicit, **no report** | Sham control |
| 7 | **G** | commit → **score-bearing** report → re-elicit | Exploratory |

## 1.4 Dual gate (frozen)

**Gate 1 — influence.** Attributed decision change rate on A–E, net of sham.
**Gate 2 — quality.** Blind classification of every attributed change into
`IMPROVED / DEFENSIBLE / UNSUPPORTED / DEGRADED`, from independently scored
**Q1** coherence, **Q2** constraint engagement, **Q3** claim support. Never summed.

**Both must pass. Neither substitutes for the other.** At n = 5, Gate 2 is a **harm screen plus
existence proof** — no benefit rate will be reported.

## 1.5 PASS — development authorised (all six)

1. Net attributed change rate **≥ 30%**
2. **≥ 3 of 5** participants show ≥ 1 attributed change
3. **≥ 2 distinct report sections** cited across the study
4. **UNSUPPORTED + DEGRADED ≤ 25%** of attributed changes
5. **≥ 2 changes coded IMPROVED, in ≥ 2 different participants**
6. `UNRESOLVED` **≤ 30%** and blinding guess accuracy **≤ 65%**

## 1.6 FAIL — the project stops (any one)

- Net rate **< 15%**
- **≥ 4 of 5** participants show zero attributed changes
- Recruitment of five qualified participants fails within the cap
- **UNSUPPORTED + DEGRADED > 40%**
- **Any single participant with ≥ 2 DEGRADED**

## 1.7 AMBIGUOUS

All other combinations, including: influence met but IMPROVED ≤ 1; harm 25–40%; change concentrated in
≤ 2 participants; `UNRESOLVED` > 30%; blinding compromised.

## 1.8 Anti-redesign rule

On FAIL: development stops · **a FAIL may not be answered by rewriting the report and re-testing**
(available once, only from AMBIGUOUS) · resumption requires a new hypothesis and a sponsor other than
the architect · 90-day pause · negative result published in full. **Applies to quality-gate failures
identically.**

## 1.9 Never a pass

High ratings · stated willingness to use · any WTP figure · enthusiasm from one participant ·
**decision change with no evidence the changes are defensible.**

## CASE A — Position materially above the hard cap

**Baseline (participant-facing).**
*NOVA — semiconductor capital equipment. Weight **28.4%** ($3.41M). Cost basis $0.83M; unrealised gain
$2.58M, all long-term. Held 3 years 2 months. 20-day ADV $210M; position is 1.6% of ADV. Sector
(technology) exposure 34.1%. Correlation to two other holdings: 0.71 and 0.66.*

**Pre-decision question.** *"What would you do with this position, and roughly how much?"*

**V3 report content.** Action `TRIM` (mandated) · magnitude "reduce by 13.4pp of portfolio (~$1.61M)" ·
policy status "28.4% vs 15.0% cap — **13.4pp over**" · portfolio impact "sector 34.1% → 30.6%; HHI
0.071 → 0.048; cluster exposure 0.71/0.66 reduced" · evidence: 3 claims, all CONTEXT tier, contributing
0, shown for and against · confidence "policy-arithmetic, near-certain — not an evidence claim" ·
elimination trace "EXIT eliminated: liquidity — full exit is 16.2 days of ADV, above the 2-day limit" ·
what changed "weight 26.1% → 28.4% on price appreciation" · what would reverse "weight below 15.0%, or
the cap is revised" · terminal-wealth disclosure · `forecast_contribution 0.0`.

**Withheld.** Subsequent prices · that this is the archetype most likely to move a decision · the
constraint list · that other cases are designed for no action.

**Expected material constraints** *(externally authored — see Part 6).* Cap breach magnitude · realised
gains budget headroom ($60k remaining vs a large embedded gain) · staging/liquidity of a $1.61M
reduction · sector cap proximity · correlation cluster.

**Plausible defensible decisions.** TRIM to the cap in one action · TRIM to the cap staged over
2–4 weeks · TRIM part-way now with a schedule · TRIM below the cap for cluster reasons · **arguing the
cap is wrong and proposing a different limit, coherently.**

**Unsupported examples.** *"Trim 13.4% because the report says to"* — deference with no reasoning ·
magnitude changes with no stated basis · confidence rising from 3 to 5 with no added reason.

**Degraded examples.** Pre engages the tax budget, post drops it entirely · post asserts *"it's
overvalued"* — a directional claim the case cannot support · post recommends full exit while the
liquidity constraint is on the page.

**Evaluator notes.** Deference is common here and is **UNSUPPORTED, not IMPROVED**. Engaging the cap is
low-value on its own — Q2 credit requires engaging **more than** the cap.

**Redaction.** Replace `13.4`, `1.61`, `0.048`, `16.2` with `[figure]` where they appear only in the
report.

**Case-specific bias risk.** The most "obvious" case; risks anchoring the whole session. **Never placed
first** in any sequence.

## CASE B — Below target with near-term event risk

**Baseline.** *HELIX — medical devices. Weight **3.1%** ($372k) vs **5.0%** target — 1.9pp below, band
is ±2pp. Cost basis $410k; unrealised loss $38k, short-term. Held 7 months. **Confirmed earnings date:
4 calendar days from today.** 20-day ADV $44M; a move to target is 3.1% of ADV. No other position in
the sector.*

**V3 report content.** Action `HOLD` · magnitude none · policy status "3.1% vs 5.0% target — 1.9pp
below, **inside** the ±2pp band" · dated catalyst "earnings T+4, confirmed, source: company IR calendar"
· elimination trace "ADD eliminated: within band, no mandate — and the dated event falls inside the 1W
and 1M horizons" · what would reverse "weight below 3.0%, or the event passes" · evidence: 2 claims,
CONTEXT, contributing 0 · `forecast_contribution 0.0`.

**Withheld.** The earnings outcome · any consensus estimate or expectation · subsequent prices.

**Expected material constraints.** Dated event inside the near horizons · band status (inside, not
breached) · wash-sale exposure from the short-term loss · position immaterial at 3.1%.

**Plausible defensible decisions.** HOLD until after the event · ADD to target now, accepting event
risk · ADD partially · HOLD and schedule a review at T+5 · exit the position as sub-scale.

**Unsupported examples.** ADD with no reference to the event · *"the report says hold"* · magnitude
change with no reasoning.

**Degraded examples.** Post asserts a directional view of the earnings result · pre notes the wash-sale
window, post abandons it · confidence rises because a date was supplied, without any view of what it
implies.

**Evaluator notes.** Both HOLD and ADD are defensible. **Engaging the dated event at all is the Q2
signal**, regardless of direction.

**Redaction.** Replace `1.9`, `3.1%` (ADV), `T+4` with `[figure]` where report-only.

**Bias risk.** Participants may infer the report "wants" HOLD. The elimination trace states no mandate
exists, which is the intended reading.

## CASE C — Highly appreciated winner with embedded gains

**Baseline.** *ATLAS — payments infrastructure. Weight **19.2%** ($2.30M). Cost basis $0.52M;
unrealised gain **$1.78M (+342%)**. Lots: 78% held > 1 year, **22% held 9 months** (short-term).
Sector (financials/tech overlap) 26.8%. 20-day ADV $95M. Realised gains budget: $60k of $180k
remaining.*

**V3 report content.** Action `TRIM` (mandated) · magnitude "reduce by 4.2pp (~$504k)" · policy status
"19.2% vs 15.0% cap — **4.2pp over**" · **tax detail: trimming 4.2pp from long-term lots realises
~$390k of gain against $60k of remaining budget** · elimination trace "EXIT eliminated: cap mandate does
not require exit; short-term lots eliminated from the sell set — 9 months held, 3 months to long-term
treatment" · what would reverse "weight below 15.0%; or the gains budget is raised; or after
[date] when short-term lots season" · `forecast_contribution 0.0`.

**Withheld.** Subsequent prices · the participant's notional tax rate · any view on valuation.

**Expected material constraints.** Cap breach · **realised-gains budget shortfall (the central tension)**
· lot seasoning (3 months to long-term) · staging across tax years · sector proximity.

**Plausible defensible decisions.** Trim to the cap and accept the tax cost · trim partially now,
complete in January · defer 3 months for lot seasoning · trim only from the oldest lots · argue the cap
should yield to the tax cost, coherently.

**Unsupported examples.** Trim to the cap with no mention of the gains budget when it is on the page ·
*"the report says 4.2%"* · deferring with no stated reason.

**Degraded examples.** Pre engages the tax cost, post ignores it and trims to the cap mechanically ·
post asserts *"it's due for a pullback"* · post proposes selling short-term lots while the report shows
they are 3 months from seasoning.

**Evaluator notes.** **The tax/cap tension is the case.** Q2 credit requires engaging the gains budget
or lot seasoning — not the cap alone. Deferring is fully defensible.

**Redaction.** `4.2`, `504`, `390`, `60k` → `[figure]` where report-only.

**Bias risk.** Highest risk of mechanical compliance. Watch for cap-satisfaction without tax reasoning.

## CASE D — Losing position still within policy · *designed answer: no action*

**Baseline.** *VERTEX — specialty chemicals. Weight **2.8%** ($336k). Cost basis $600k; unrealised loss
**$264k (−44%)**, all long-term. Held 2 years 4 months. Target weight 3.0%, band ±2pp — **inside**.
Sector 8.2% of portfolio. 20-day ADV $18M; full exit is 1.9% of ADV. No dated events. Realised losses
year-to-date: $0.*

**V3 report content.** Action `HOLD` · magnitude none · policy status "2.8% vs 3.0% target — 0.2pp
below, **inside** the band. No limit breached" · elimination trace "TRIM eliminated: no breach, no
mandate. EXIT eliminated: no breach, no mandate. ADD eliminated: no breach, no mandate" · **abstention
statement: "no admissible evidence discriminates between actions at any horizon; the platform has no
reliable directional view"** · note "an exit would realise a $264k loss, available against the realised
gains budget" · what would reverse "weight outside 1.0–5.0%; or a dated event" ·
`forecast_contribution 0.0`.

**Withheld.** Subsequent prices · that this case tests **false-positive action** · any view on the
business.

**Expected material constraints.** No breach exists · tax-loss harvesting availability against a used
gains budget · position immaterial · no dated events · wash-sale implications of any repurchase.

**Plausible defensible decisions.** HOLD · EXIT to harvest the loss against realised gains · trim
partially to harvest · **no action, explicitly reasoned.**

**Unsupported examples.** TRIM or EXIT with the reason *"it's down"* or *"cut losers"* with no reference
to policy or tax · any change with no stated basis.

**Degraded examples.** Post asserts *"the thesis is broken"* — a directional claim the case cannot
support · pre notes the loss-harvest opportunity, post drops it · confidence rises after reading a page
that explicitly states no directional view.

**Evaluator notes.** **HOLD and harvest-the-loss are both fully defensible; this case has no single
correct action.** The Q2 signal is engaging the loss-harvest option against the gains budget. Watch for
degradation via manufactured conviction.

**Redaction.** `264`, `0.2pp`, `1.9%` → `[figure]` where report-only.

**Bias risk.** Participants may assume every case demands action. The abstention statement is the
intended counterweight.

## CASE E — Conflicting evidence, no defensible directional view · **HARM PROBE**

**Baseline.** *ORION — industrial software. Weight **8.1%** ($972k) vs 8.0% target — 0.1pp over, band
±2pp, **inside**. Cost basis $700k; unrealised gain $272k, long-term. Held 1 year 8 months. Sector
19.4%. 20-day ADV $61M. No dated events within 30 days.*

**V3 report content.** Action `HOLD` · **abstained: true** · magnitude none · policy status "inside all
limits" · **evidence shown in two columns, unreconciled**: *supporting reduction* — relative price
trend negative over 6 months (CONTEXT, contributing 0); sector momentum negative (CONTEXT, 0).
*Supporting retention* — revenue-quality metric in the top decile of its own 3-year range (CONTEXT, 0);
correlation to the rest of the book below average (CONTEXT, 0) · **abstention statement: "These claims
point in opposite directions. No source has demonstrated out-of-sample directional reliability at any
horizon. The platform has no defensible directional view and does not average these into one."** ·
elimination trace "all actions remain feasible; none is mandated; no admissible evidence discriminates"
· what would reverse "any limit breach; a dated event; or a source reaching ADVISORY tier" ·
`forecast_contribution 0.0`.

**Withheld.** Subsequent prices · that abstention is the designed outcome · that this is the harm probe.

**Expected material constraints.** No breach · genuine evidential conflict · absence of any dated
catalyst · position is material at 8.1% but within band.

**Plausible defensible decisions.** HOLD, explicitly on the ground that nothing discriminates · HOLD and
set a monitoring trigger · trim modestly on personal risk preference, **stated as preference not as a
view** · state one's own directional view **and label it as one's own**.

**Unsupported examples.** Any action change citing the conflicting evidence as though it resolved ·
*"the report leans negative"* — it does not · confidence rising after reading an explicit abstention.

**Degraded examples.** **Pre: "hold, no strong view, confidence 2." Post: "trim 6%, confidence 4"**
citing conflicting evidence as directional. *This is the primary harm signature the study exists to
detect.*

**Evaluator notes.** **Highest-priority case.** Q3 is the operative dimension. Any post record asserting
direction on the strength of the presented conflict scores **Q3 = 0**.

**Redaction.** `8.1%`, `0.1pp`, "top decile" → `[figure]` / `[characterisation]` where report-only.

**Bias risk.** Participants may read abstention as a product defect and over-act to demonstrate
expertise. **The debrief probes this directly and must not be skipped.**

# PART 3 — PARTICIPANT MATERIALS

## 3.1 Recruitment message

> **Subject: 90 minutes — feedback on portfolio report formats ($100)**
>
> I'm running a small study on how portfolio decision reports are read by people who actually make
> position decisions. I'm looking for five participants who currently manage or materially influence a
> real portfolio.
>
> It's a 90-minute recorded video session. I'll show you several positions and ask what you'd do, then
> show additional material and ask again. There are no right answers, and finding that a format doesn't
> help is as useful to me as finding that it does.
>
> $100 for your time. I'm not selling anything and there's no follow-up unless you want one.
>
> Reply and I'll send five screening questions.

## 3.2 Screener

| # | Question | Disqualify if |
|---|---|---|
| 1 | Do you currently make or materially influence buy/sell/size decisions on an investment portfolio? | No |
| 2 | Whose capital? *(own only → Track B; others' → Track A)* | — |

| 5 | Roughly how many positions? | < 10 |
| 6 | Typical holding period? | < 1 week |

| 10 | Available 90 minutes, recorded, in the next three weeks? | No |

> Thanks — you qualify. Here's a link to book a 90-minute slot: [link]
>
> Please join from somewhere you can look at a screen and talk for the full session. You don't need to

## 3.5 Neutral introduction *(read verbatim)*

> Thank you for the time. I'm evaluating some portfolio report formats. I did not design them and I have
> no stake in which one performs better.
>

> that doesn't change anything is exactly what I need to find out.
>
> Please think aloud. If something is unclear, confusing, or not worth reading, say so plainly — that is
> the most useful thing you can tell me. Any questions before we start?

# PART 4 — MODERATOR PACKAGE

## 4.1 Moderator requirements

Not the architect · has not read any project document beyond this Part 4 · has not seen the reports
before the briefing · reads scripts verbatim.

## 4.2 Timing guide (90 minutes)

| Segment | Minutes | Cumulative |
|---|---|---|
| Consent + introduction (§3.3, §3.5) | 5 | 5 |
| Warm-up case *(discarded)* | 5 | 10 |
| Cases 1–7 @ 8 min | 56 | 66 |
| Final questionnaire (§3.8) | 15 | 81 |
| Debrief (§3.9) | 5 | 86 |
| Buffer | 4 | 90 |

**Per case (8 min):** baseline 2 · commit + form 2 · reveal 2 · re-elicit + form 1.5 · probes 0.5.
**If running > 5 minutes behind at case 4, shorten probes, never the commit phase.**

## 4.3 Scripts

**Commit phase**
> "Here's a position and the relevant portfolio context. Take as long as you need. When you're ready:
> **what would you do with this position, and roughly how much?**"
> *[record verbatim]*
> "Please write that on the form — action, size, confidence 1 to 5, and in one line the main reason."
> ***[moderator confirms the form is complete before revealing anything]***

**Reveal phase**
> "Here's some additional material on the same position. Read it however you normally would. Tell me
> when you're done."

**Re-elicit**
> "Now: **what would you do with this position, and roughly how much?**"
> *[record]* "Please complete the second form."

**Probes** *(only after the post-form is complete)*
> "Talk me through how you got to that."
> *if changed:* "What specifically led you there?" → *if vague:* "Can you point to the part of the page?"
> *if unchanged:* "Was there anything there you'd have acted on in a different situation?"
> "Was anything on that page not worth your time?"

**Sham distractor (Case F, exactly 3 minutes, timed)**
> "Before you finalise — something unrelated. How often do you normally review positions like this one?
> … And what usually prompts a review outside that cadence? … Who else, if anyone, sees it?"
> *[at 3:00]* "Coming back to that position — what would you do, and roughly how much?"

## 4.4 Prohibited statements

Never say: *did this help* · *do you like* · *would you find it useful* · *was it better* · *improve* ·
*powerful* · *sophisticated* · *rigorous* · *correct* · *most people* · *we built* · *the system
recommends* · anything indicating a preferred condition, that cases differ by design, or that any case
has a right answer.

## 4.5 Interruption rules

Do **not** interrupt during reading or think-aloud. Interrupt **only** to: enforce the 3-minute sham
timer · stop a case running past 10 minutes ("let's capture where you are and move on") · handle a
technical failure. Never interrupt to clarify, correct, or redirect reasoning.

## 4.6 Clarification rules

| Participant asks | Moderator says |
|---|---|
| What does this section mean? | "Whatever it means to you — that's part of what I'm trying to learn." |
| Is that the right answer? | "There's no right answer here." |
| What would you do? | "I'm not in a position to say — I'd rather have your read." |
| Where's the report? *(Case F)* | "Some cases have one and some don't. Go with what you have." |
| What's this study for? | "Comparing report formats. I'll explain fully at the end." |
| Is this a real company? | "All the positions are fictional composites." |

**Any question not on this list: "I'd rather not steer you — go with your own read," then log it.**

## 4.7 Protocol-deviation log *(one row per event)*

# PART 5 — BLINDED EVALUATION PACKAGE

## 5.1 Evaluator criteria

Three evaluators meeting the Track A screener (§3.2). **Excluded:** the architect · the moderator · any
participant · anyone who has read any project document. **At least one must have had no exposure to this
project of any kind.** Paid $40 each, ~2 hours.

## 5.2 Evaluator briefing *(complete text — nothing further is disclosed)*

> Thank you for helping. You'll receive a set of investment decision records. Each one contains a short
> description of a position and portfolio, the action someone chose, the size, their stated confidence,
> and their reasoning in their own words.
>
> For each record, score three things using the rubrics provided, and note which constraints from the
> supplied list the reasoning engages with. The records are in random order and are not related to each
> other.
>
> There are no right actions. Several different actions may be equally sound on the same facts. You are
> **not** scoring whether you agree with the decision. You are scoring whether the reasoning holds
> together, whether it engages what matters in the case, and whether it claims more than the information
> supports.
>
> Work independently. Do not discuss with anyone. Allow about two hours.

*(Evaluators are **not** told that reports exist, that records are paired, that conditions differ, or
what is being tested.)*

## 5.3 Randomised record format

One record per page, shuffled across participants and cases. **No pairs adjacent.**

```
RECORD ID: R-0417                     CASE: A            [case baseline reproduced in full]

ACTION: TRIM        MAGNITUDE: 8% of portfolio        STATED CONFIDENCE: 4 / 5

REASONING (verbatim):
"________________________________________________________________"

────────────────────────────────────────────────────────────────
Q1 Reasoning–action coherence      ▢ 2   ▢ 1   ▢ 0
Q2 Constraints engaged (tick all)  ▢ A1  ▢ A2  ▢ A3  ▢ A4  ▢ A5   ▢ none
Q3 Claim support                   ▢ 2   ▢ 1   ▢ 0
UNSUP flag — reasoning asserts something not present in the case,
             or defers to an external source without reasoning   ▢ yes  ▢ no
BLINDING — was this written before or after the person saw
           additional material?    ▢ before  ▢ after  ▢ can't tell
Note (optional): ______________________________________________
```

**Record IDs are non-sequential and carry no participant, case-order or condition information.**

## 5.4 Q1 — Reasoning–action coherence

| Score | Anchor |
|---|---|
| **2** | The action follows from the stated reason **and** the magnitude is connected to it |
| **1** | The action follows, but the magnitude is unstated, arbitrary, or unconnected to the reason |
| **0** | The action does not follow from the stated reason, the reason is absent, or reason and action contradict |

*Not scored: whether you would have chosen the same action.*

## 5.5 Q2 — Material-constraint engagement

Tick each constraint from the case's supplied list that the reasoning **explicitly engages** — names it,
or clearly addresses it in substance. Passing mention without bearing on the decision does not count.
**Do not tick constraints the reasoning does not raise, even if you think it should have.**
**Recorded as a set, not a score.**

## 5.6 Q3 — Claim support

| Score | Anchor |
|---|---|
| **2** | No directional assertion beyond what the information supports; stated confidence is proportionate |
| **1** | Mild overreach, or confidence somewhat beyond the stated basis |
| **0** | Asserts a directional view the information cannot support, **or** confidence is clearly disproportionate to the basis given |

*A stated personal view labelled as a personal view is **not** an overreach. An unlabelled assertion
presented as fact is.*

## 5.7 The five classifications *(computed by the analyst, not the evaluator)*

Applied to linked pre/post records after scoring. **Strict precedence, top to bottom.**

| Code | Rule |
|---|---|
| **UNCHANGED** | No `CHANGE-A` and no `CHANGE-M` |
| **DEGRADED** | Change occurred **and** ( Q1_post < Q1_pre **or** Q3_post < Q3_pre **or** Q2_post ⊊ Q2_pre ) |
| **UNSUPPORTED** | Change occurred **and** `UNSUP_post = yes` **and** not DEGRADED |
| **IMPROVED** | Change occurred **and** Q2_post ⊋ Q2_pre **and** Q1_post ≥ Q1_pre **and** Q3_post ≥ Q3_pre |
| **DEFENSIBLE** | Change occurred and none of the above |

## 5.8 Adjudication

2-of-3 agreement on a dimension sets the code. Applied per dimension, not per record.
Q2 majority rule: a constraint is "engaged" if **≥ 2 of 3** evaluators ticked it.

## 5.9 Unresolved procedure

No 2-of-3 majority on Q1, Q3, or `UNSUP` → that **dimension** is `UNRESOLVED`. Any record with an
unresolved dimension makes its **classification** `UNRESOLVED`. Not adjudicated further, **not forced,
not discarded.** `UNRESOLVED` rate = unresolved classifications ÷ attributed changes.

## 5.10 Evaluator disagreement log

```
Record ID | Dimension | E1 | E2 | E3 | Majority? | Resolution | Note
```

Completed for **every** record where evaluators differ, whether or not a majority exists. Reported in
the final document.

## 6.1 Instructions to the constraint author

> You are defining, for each of six fictional portfolio cases, the list of **material constraints** —
> the facts a competent professional would need to engage with to reason about that position properly.
>
> **A material constraint is:** a stated limit, a tax or accounting consequence, a liquidity or execution
> reality, a dated event, or a portfolio-structural fact (concentration, correlation, sector) that is
> **present in the case description** and would bear on a reasonable decision.
>
> **Do NOT include:** any view on what the right action is · any directional opinion about the security ·
> anything not present in the material you are given · anything you think *should* have been provided

## 7.2 Derived-field rules

```
CHANGE-A  = action_POST ≠ action_PRE
CHANGE-M  = |mag_POST − mag_PRE| ≥ 2.0 (pp of portfolio)
            OR |mag_POST − mag_PRE| / max(mag_PRE, 0.1) ≥ 0.25
            (if exactly one of PRE/POST is null → CHANGE-M = true)
ATTRIB    = sections_ticked contains ≥1 entry other than "none of these"
            OR reasoning_text names a report section unprompted (coder-confirmed)
COUNTED   = (CHANGE-A OR CHANGE-M) AND ATTRIB
```

## 7.3 Exact calculation rules

```
--- GATE 1 ---
n_conf              = count(classifications)                       [expected 25]
counted_conf        = count(COUNTED = true, case_type=CONFIRMATORY)
raw_change_rate     = counted_conf / n_conf
sham_changes        = count(CHANGE-A OR CHANGE-M, case_id = F)     [max 5]
sham_rate           = sham_changes / 5
NET_CHANGE_RATE     = raw_change_rate − sham_rate                  ← GATE 1 PRIMARY

participants_with_change = count(distinct participant_id WHERE any COUNTED = true)
distinct_sections   = count(distinct entries across sections_ticked, excl. "none of these")

--- GATE 2 ---   denominator = attributed changes only
D                   = counted_conf
n_improved          = count(classification = IMPROVED)
n_defensible        = count(classification = DEFENSIBLE)
n_unsupported       = count(classification = UNSUPPORTED)
n_degraded          = count(classification = DEGRADED)
n_unresolved        = count(classification = UNRESOLVED)

HARM_RATE           = (n_unsupported + n_degraded) / D             ← GATE 2 PRIMARY
UNRESOLVED_RATE     = n_unresolved / D
improved_participants = count(distinct participant_id WHERE classification = IMPROVED)
max_degraded_per_participant = max over participants of count(DEGRADED)

--- BLINDING INTEGRITY ---
guesses_made        = count(blinding_guess ≠ CANT_TELL)
BLINDING_ACCURACY   = count(correct = true) / guesses_made

--- DECISION ---
PASS   ⇔ NET_CHANGE_RATE ≥ 0.30
       ∧ participants_with_change ≥ 3
       ∧ distinct_sections ≥ 2
       ∧ HARM_RATE ≤ 0.25
       ∧ n_improved ≥ 2 ∧ improved_participants ≥ 2
       ∧ UNRESOLVED_RATE ≤ 0.30 ∧ BLINDING_ACCURACY ≤ 0.65

FAIL   ⇔ NET_CHANGE_RATE < 0.15
       ∨ participants_with_change ≤ 1
       ∨ recruitment_failed = true
       ∨ HARM_RATE > 0.40
       ∨ max_degraded_per_participant ≥ 2

AMBIGUOUS ⇔ ¬PASS ∧ ¬FAIL
```

**Precedence: FAIL is evaluated first. If any FAIL condition holds, the result is FAIL regardless of
PASS conditions.**

**Case G is excluded from every numerator and denominator above.**
